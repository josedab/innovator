# Copilot Extension Setup Guide

Use Innovator directly inside GitHub Copilot Chat — in VS Code, GitHub.com, or any IDE with Copilot support. Type `@innovator` followed by a command to run investigations, generate ideas, and synthesize insights without leaving your editor.

## Prerequisites

- GitHub Copilot subscription (Individual, Business, or Enterprise)
- VS Code with the [GitHub Copilot Chat](https://marketplace.visualstudio.com/items?itemName=GitHub.copilot-chat) extension, or access to GitHub.com Copilot Chat
- The Innovator backend running (local dev server or deployed instance)

## Step 1: Register the GitHub App

Innovator uses a GitHub App to integrate with Copilot Extensions. Register it with the built-in manifest:

```ts
import { GITHUB_APP_MANIFEST } from "@innovator/core";

// Use this manifest when registering at:
// https://github.com/settings/apps/new
console.log(JSON.stringify(GITHUB_APP_MANIFEST, null, 2));
```

Or register manually at [github.com/settings/apps/new](https://github.com/settings/apps/new) with these settings:

| Setting          | Value                                |
| ---------------- | ------------------------------------ |
| **App name**     | Innovator                            |
| **Description**  | AI-Powered Innovation Engine         |
| **Homepage URL** | Your deployment URL                  |
| **Webhook URL**  | `https://<your-domain>/api/webhooks` |
| **Public**       | Yes                                  |

## Step 2: Configure the Copilot Agent

After registering the GitHub App, enable it as a Copilot Extension:

1. Go to your GitHub App settings → **Copilot** tab
2. Set the **Agent** endpoint to: `https://<your-domain>/api/copilot`
3. Enable **Auth token forwarding** (allows the agent to make authenticated LLM calls)

The agent manifest is generated by `getCopilotAgentManifest()`:

```ts
import { getCopilotAgentManifest } from "@innovator/core";

const manifest = getCopilotAgentManifest();
// Returns the full agent config with all command definitions
```

## Step 3: Install the App

1. Go to your GitHub App's public page
2. Click **Install** and select the repositories/organization
3. In VS Code, the `@innovator` agent will appear in Copilot Chat

## Usage

### Available Commands

| Command                            | Description                     | Example                                   |
| ---------------------------------- | ------------------------------- | ----------------------------------------- |
| `@innovator investigate <subject>` | Analyze a subject               | `@innovator investigate renewable energy` |
| `@innovator innovate <subject>`    | Generate ideas using all angles | `@innovator innovate remote work tools`   |
| `@innovator auto <subject>`        | Full pipeline with synthesis    | `@innovator auto AI-powered education`    |
| `@innovator angles`                | List available angles           | `@innovator angles`                       |
| `@innovator presets`               | Browse domain presets           | `@innovator presets`                      |
| `@innovator help`                  | Show help                       | `@innovator help`                         |

### Quick Start Examples

**Investigate a subject:**

```
@innovator investigate sustainable packaging
```

**Run the full innovation pipeline:**

```
@innovator auto developer onboarding
```

**Just type a subject** (defaults to `auto`):

```
@innovator AI-powered code review
```

### How It Works

1. You type `@innovator <command>` in Copilot Chat
2. GitHub forwards the message to the Innovator agent endpoint
3. The agent parses the slash command via `parseSlashCommand()`
4. The request is dispatched to the appropriate handler via `handleCopilotRequest()`
5. Results are formatted as Markdown and returned to the chat

### Response Format

Responses are formatted for chat readability with:

- Emoji-prefixed section headers
- Structured lists for aspects, challenges, and opportunities
- Idea cards with impact and feasibility ratings
- Collapsible sections for long content

## Local Development

To test the Copilot Extension locally:

1. Start the dev server:

   ```bash
   npm run dev
   ```

2. Use a tunnel (e.g., ngrok) to expose the local server:

   ```bash
   ngrok http 3000
   ```

3. Update your GitHub App's webhook and agent URLs to the tunnel URL

4. Test in VS Code Copilot Chat with `@innovator investigate <subject>`

## Programmatic Usage

You can also use the extension module directly in custom integrations:

```ts
import {
  parseSlashCommand,
  handleCopilotRequest,
  formatInvestigationForChat,
} from "@innovator/core";

// Parse a chat message
const cmd = parseSlashCommand("@innovator investigate solar energy");
// { command: "investigate", args: "solar energy", rawInput: "..." }

// Handle a full request
const response = await handleCopilotRequest(userMessage, {
  investigate: async (subject) => {
    return await investigate(subject);
  },
  auto: async (subject, onProgress) => {
    // Run pipeline with progress callbacks
    return { results: angleResults, synthesis };
  },
});

console.log(response.markdown);
```

## Troubleshooting

### "Agent not found" in Copilot Chat

- Verify the GitHub App is installed on your repository/organization
- Check that the Copilot Extension agent endpoint is configured correctly
- Ensure the endpoint returns proper Copilot Extension response format

### Timeout errors

- Investigations with all angles can take 2–5 minutes
- Consider using `investigate` for quick results instead of `auto`
- Check that your deployment has adequate timeout settings (≥5 minutes)

### Empty responses

- Verify the backend has access to an LLM provider (Copilot, OpenAI, etc.)
- Check server logs for LLM errors
- Ensure the `GITHUB_TOKEN` is forwarded correctly (auth token forwarding must be enabled)
